# Aster originals

Select these at the top of Aster’s Presets screen. Each is a complete prompt configuration, staged for review before adoption. Designed for dark terminals; Aurora Powerline and Ember use powerline separators. Nerd Fonts are recommended for branch and lock icons.

| Preset | Look |
| --- | --- |
| Prism | Terminal-palette accents, spacious two-line constellation rails |
| Prism Powerline | Rounded ribbon using terminal purple → cyan → green |
| Aurora | Lavender and cyan constellation rails, spacious two-line prompt |
| Aurora Powerline | Lavender → cyan → mint rounded ribbon |
| Obsidian | Cool graphite, restrained geometry, right-side clock |
| Midnight Circuit | Electric mint and periwinkle, technical rails |
| Moonstone | Soft lilac moon, compact single line |
| Ember | Warm amber capsule, smoked copper branch segment |
| Deep Forest | Moss and teal botanical rails |

Duration appears after commands lasting at least two seconds. Git segments appear inside repositories. No custom shell commands are used.

Prism and Prism Powerline follow the terminal’s ANSI palette automatically. They use purple, cyan, and green accents, red errors, and black text inside powerline segments. They contain no fixed RGB or indexed colors. Prism Powerline requires a font with powerline glyphs.
